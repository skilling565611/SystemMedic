# SystemMedic
Laptop-first lightweight Windows maintenance suite for health monitoring, cleanup, optimization, backup, and recovery.

## Workstation Bootstrap

Fresh-machine setup automation lives in `Bootstrap/`.

Run a safe preview first:

```bat
Bootstrap.bat -DryRun -Yes
```

See `Bootstrap/README.md` for configuration, portable Python payloads, VS Code imports, utility installers, and driver package notes.
